The central `loso` directory contains the 13-fold cross-narrative result,
story-and-participant holdout, temporal-shift null, ridge sensitivities,
within-story analyses, and Figure 2. The other directories contain the
all-13 representation, individual, component, embedding, hemisphere, and
normalization analyses.

Participant-level result rows, raw embeddings, ROI caches, machine-specific
configurations, and downloaded imaging/audio files remain local.
