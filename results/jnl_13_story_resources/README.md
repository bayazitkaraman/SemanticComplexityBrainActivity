# Local All-13 Resources

The active scripts use the following unified local directories:

```text
rich_audio_regressors/   One regressor CSV for each of the 13 stories
roi_cache/               567 participant ROI time-series files
hemisphere_roi_cache/    567 participant hemisphere ROI files
```

The resource files are excluded from Git because they contain machine-specific
or participant-level derived data. This README records the expected layout.
